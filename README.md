# Mi Mundo 🌈

Mi Mundo es una pequeña aplicación web en español con apoyos visuales para niñas y niños: reconocer emociones, comunicar necesidades, elegir apoyos sensoriales y acompañar una rutina diaria.

## Cómo usar

Abre `index.html` en un navegador. No requiere instalar dependencias ni ejecutar un servidor.

## Publicar con GitHub Pages

1. Entra a **Settings** del repositorio.
2. Abre **Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Elige la rama `main` y la carpeta `/ (root)`; guarda los cambios.
5. Espera a que GitHub Pages publique el sitio. La URL aparecerá en la misma sección.

## Nota

Este recurso es orientativo y personalizable. No sustituye el acompañamiento de la familia ni de profesionales. Respeta las preferencias sensoriales y de comunicación de cada niño.
